What a valid signature means

  • The header and payload were not modified since they were signed with the matching key.
  • It does not prove the key belongs to a trusted issuer — the server decides which keys it trusts.
  • Expiration, issuer, audience and authorization rules are still evaluated separately.
  • Keys and secrets stay in memory only and are discarded on "Clear keys" or page reload.
